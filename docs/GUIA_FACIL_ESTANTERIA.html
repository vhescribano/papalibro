Guía fácil de Estantería

Para organizar, encontrar y prestar libros sin complicaciones

Empiece por aquí. Estantería sirve para saber si tenemos un libro, dónde está guardado y a quién se lo hemos prestado.

Las palabras que verá

PalabraQué significa
LibroUn título, por ejemplo Matilda.
CopiaUn ejemplar físico. Puede haber varias copias del mismo libro.
ColecciónUn grupo de libros, por ejemplo Infantil o Historia local.
DisponibleEl libro está en la biblioteca.
PrestadoEl libro está fuera de la biblioteca.

Buscar un libro

  1. Arriba de la pantalla hay una caja de búsqueda.
  2. Escriba el título, el autor o una parte de ellos.
  3. Mire el resultado: Disponible significa que está en la biblioteca; Prestado, que está fuera.
  4. Pulse la portada para ver más información, como la ubicación.
Consejo. Si no encuentra un libro, pruebe con una sola palabra del título o con el apellido del autor.

Añadir un libro

  1. Pulse Añadir libro.
  2. Escriba el título. Es lo único imprescindible.
  3. Elija una colección y escriba dónde se guarda.
  4. Escriba cuántas copias tiene.
  5. Pulse Guardar libro.

No hace falta rellenar todos los datos. Siempre puede corregirlos más tarde.

Añadir con código de barras

  1. Pulse Añadir libro.
  2. Escriba los números del ISBN que están debajo del código de barras.
  3. Pulse Completar por ISBN.
  4. Revise los datos y pulse Guardar libro.

También puede pulsar Escanear ISBN o Cámara, permitir la cámara y mantener el código quieto y con buena luz.

Si la cámara no funciona. Escriba los números a mano o use un lector de códigos USB.

Prestar y devolver

Para prestar

  1. Busque el libro y compruebe que pone Disponible.
  2. Pulse la portada y después Prestar una copia.
  3. Escriba el nombre de la persona y revise la fecha de devolución.
  4. Pulse Confirmar préstamo.

Para devolver

  1. Pulse Préstamos en el menú.
  2. Busque el libro.
  3. Pulse Devolver.

Guardar una copia de seguridad

  1. Pulse Datos y ajustes.
  2. Pulse Descargar respaldo JSON.
  3. Guarde el archivo en una carpeta fácil de encontrar.
Buen hábito. Haga una copia una vez al mes y antes de hacer muchos cambios.

Recuperar una copia

  1. Pulse Datos y ajustes.
  2. Pulse Elegir archivo.
  3. Busque el archivo de copia de seguridad y ábralo.

Atención: recuperar una copia reemplaza la lista actual.

Problemas frecuentes

Si ocurre esto...Pruebe esto...
No encuentro un libroEscriba una palabra del título o el apellido del autor.
La cámara no lee el códigoBusque más luz, limpie el código o escriba los números.
He prestado un libro por errorAbra Préstamos y pulse Devolver.
Voy a cambiar de ordenadorDescargue una copia y recupérela en el nuevo ordenador.
