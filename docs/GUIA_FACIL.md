# Guía fácil de Estantería

Esta guía es para usar la biblioteca sin necesidad de saber informática. No hay que crear una cuenta ni recordar contraseñas.

## Lo más importante

Estantería sirve para responder tres preguntas:

1. ¿Tenemos este libro?
2. ¿Dónde está guardado?
3. ¿A quién se lo hemos prestado?

## Las palabras que verá en pantalla

| Palabra | Quiere decir |
| --- | --- |
| **Libro** | El título, por ejemplo *Matilda*. |
| **Copia** | Un ejemplar físico. Puede haber dos o más copias del mismo libro. |
| **Colección** | Un grupo de libros, por ejemplo “Infantil” o “Historia local”. |
| **Disponible** | El libro está en la biblioteca. |
| **Prestado** | El libro está fuera de la biblioteca. |

## Antes de empezar

Al abrir la aplicación verá una columna verde a la izquierda. Es el menú. Desde ahí puede ir a:

- **Inicio**: la pantalla principal.
- **Catálogo**: todos los libros.
- **Colecciones**: los grupos de libros.
- **Préstamos**: libros que tiene otra persona.
- **Inventario**: cada ejemplar que hay en la biblioteca.

En móvil, pulse el botón con tres rayas `☰` para abrir el menú.

## Buscar un libro

1. Arriba de la pantalla hay una caja que dice “Busca por título, autor, ISBN o etiqueta”.
2. Escriba el nombre del libro o de su autor.
3. Aparecerán los resultados.
4. Debajo de cada libro verá si está **Disponible** o **Prestado**.

Puede pulsar la portada para ver más información, como dónde se guarda el libro.

## Añadir un libro nuevo

1. Pulse el botón **Añadir libro**.
2. Escriba el título. Es lo único imprescindible.
3. Si conoce el autor, escríbalo también.
4. Elija la colección donde quiere guardarlo.
5. En “Ubicación”, escriba dónde está. Por ejemplo: `Sala grande, estante 2, balda de arriba`.
6. En “Cantidad de copias”, escriba cuántos ejemplares tiene.
7. Pulse **Guardar libro**.

No se preocupe si no conoce todos los datos. Puede volver a abrir el libro y corregirlo más tarde.

## Añadir un libro usando el código de barras

El código de barras suele estar detrás del libro. Debajo aparecen muchos números: eso se llama ISBN.

Puede hacerlo de dos maneras:

### Con los números del libro

1. Pulse **Añadir libro**.
2. Escriba los números que aparecen debajo del código de barras.
3. Pulse **Completar por ISBN**.
4. Espere unos segundos. Si se encuentra el libro, se rellenarán varios datos solos.
5. Revise la información y pulse **Guardar libro**.

### Con la cámara

1. Pulse **Escanear ISBN** o el botón **Cámara**.
2. Si el navegador pregunta si puede usar la cámara, pulse **Permitir**.
3. Ponga el código de barras dentro de la imagen de la cámara.
4. Espere un momento sin mover mucho el libro.

Si la cámara no funciona, no pasa nada: escriba los números a mano. También puede usar un lector de códigos de barras conectado por USB.

## Crear un grupo de libros

Los grupos ayudan a encontrar las cosas. Puede crear, por ejemplo:

- Infantil
- Novela
- Cocina
- Club de lectura
- Historia del pueblo

Para crear uno:

1. Pulse **Colecciones** en el menú.
2. Pulse **Nueva colección**.
3. Escriba el nombre.
4. Pulse **Crear colección**.

Después, al añadir un libro, podrá elegir ese grupo.

## Prestar un libro

Antes de prestar, busque el libro y compruebe que pone **Disponible**.

1. Pulse la portada del libro.
2. Pulse **Prestar una copia**.
3. Escriba el nombre de la persona que se lo lleva.
4. Compruebe la fecha de devolución. Puede cambiarla si lo necesita.
5. Pulse **Confirmar préstamo**.

El libro pasará a aparecer como **Prestado**. Así nadie lo buscará pensando que está en la estantería.

## Cuando devuelven un libro

1. Pulse **Préstamos** en el menú.
2. Busque el nombre del libro o de la persona.
3. Pulse el botón **Devolver**.

Ya está. El libro vuelve a estar disponible.

## Si quiere saber dónde está un ejemplar

1. Pulse **Inventario**.
2. Busque el libro.
3. Mire la columna “Ubicación”.

Si la ubicación no ayuda, abra la ficha del libro y cámbiela por una más clara. Es mejor escribir lugares que todo el mundo entienda.

## Guardar una copia de seguridad

Una copia de seguridad es un archivo que guarda la lista de libros. Es importante porque permite recuperar la biblioteca si cambia de ordenador o se borra algo sin querer.

1. Pulse **Datos y ajustes** en el menú.
2. Pulse **Descargar respaldo JSON**.
3. El navegador descargará un archivo.
4. Guárdelo en una carpeta fácil de encontrar, por ejemplo `Documentos > Copias biblioteca`.

Un buen hábito es hacer una copia de seguridad una vez al mes y antes de hacer muchos cambios.

## Recuperar una copia de seguridad

Si alguien le ha dado una copia de seguridad o ha cambiado de ordenador:

1. Pulse **Datos y ajustes**.
2. Pulse **Elegir archivo**.
3. Busque el archivo de copia de seguridad y ábralo.

> Atención: al recuperar una copia se reemplaza la lista que estaba en pantalla. Si tiene dudas, haga primero una copia nueva de lo que hay ahora.

## Borrar todo y empezar de nuevo

Solo use esta opción si está completamente seguro.

1. Pulse **Datos y ajustes**.
2. Pulse **Borrar base de datos local**.
3. Lea el aviso y confirme únicamente si de verdad desea borrar todos los libros.

Antes de borrar, descargue siempre una copia de seguridad.

## Pequeños consejos

- No intente rellenar todos los campos: título, ubicación y número de copias suelen ser suficientes al principio.
- Escriba las ubicaciones siempre de la misma manera. Por ejemplo: `Infantil, estante 1, balda 2`.
- Si un libro no aparece, búsquelo por una parte del título o por el apellido del autor.
- Si no sabe qué botón pulsar, vuelva a **Inicio**: allí están las acciones más habituales.
- Los datos se quedan en este navegador. Para verlos en otro ordenador, descargue una copia y recupérela allí.

## Si algo no sale como esperaba

| Problema | Qué puede probar |
| --- | --- |
| No encuentro un libro | Escriba solo una palabra del título o el apellido del autor. |
| La cámara no lee el código | Limpie el código, acerque más luz o escriba los números manualmente. |
| He prestado un libro por error | Abra Préstamos y pulse Devolver. |
| He cambiado un dato mal | Abra el libro, pulse Editar ficha y corríjalo. |
| Voy a cambiar de ordenador | Descargue una copia de seguridad y llévela al nuevo ordenador. |
