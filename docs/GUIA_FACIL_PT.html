Guia fácil do Papa Livro

Um guia calmo e prático para organizar livros sem conhecimentos técnicos.

As três perguntas importantes

  • Temos este livro?
  • Onde está guardado?
  • A quem o emprestámos?

Antes de começar

  • O Papa Livro funciona no navegador e não precisa de conta nem palavra-passe. O catálogo fica neste computador e neste navegador.
  • Use o menu à esquerda: Início, Catálogo, Coleções, Empréstimos, Inventário e Dados e definições. No telemóvel, carregue no botão com três linhas.

Encontrar um livro

  • Use a caixa de pesquisa no topo. Escreva parte do título, o autor, um ISBN ou uma etiqueta.
  • Cada resultado mostra Disponível quando existe um exemplar na biblioteca, Emprestado quando todos saíram, ou Sem exemplares quando existe apenas a ficha.
  • Selecione uma capa para ver a ficha completa e a localização.

Adicionar um livro

  • Carregue em Adicionar livro. O título é o único campo indispensável.
  • Escolha uma coleção e escreva uma localização clara, por exemplo: Sala principal - Estante B - Prateleira 2.
  • Indique quantos exemplares físicos tem e escolha Guardar livro. Pode corrigir os detalhes mais tarde.

Adicionar com código de barras

  • Carregue em Adicionar livro, escreva o ISBN que aparece sob o código de barras e escolha Preencher por ISBN. Confirme o resultado antes de guardar.
  • Também pode escolher Digitalizar ISBN ou Câmara e permitir o acesso à câmara. Mantenha o código parado e bem iluminado. Se não funcionar, escreva os números ou use um leitor USB.

Criar coleções

  • As coleções facilitam o uso do catálogo: Infantil, Cozinha, História local ou Clube de leitura.
  • Abra Coleções, escolha Nova coleção, dê-lhe um nome e carregue em Criar coleção. Escolha-a quando adicionar ou editar um livro.

Emprestar e devolver

  • Abra um livro disponível e escolha Emprestar um exemplar. Indique o nome da pessoa, a data de saída e a data prevista de devolução e confirme.
  • Quando o livro voltar, abra Empréstimos e escolha Devolver. O exemplar fica disponível imediatamente.

Verificar exemplares

  • Abra Inventário para ver cada exemplar físico, o código interno, a localização, o estado de empréstimo e a conservação. É útil durante uma conferência do acervo.

Fazer uma cópia de segurança

  • Abra Dados e definições e escolha Descarregar cópia JSON. Guarde o ficheiro numa pasta fácil de encontrar, por exemplo Documentos > Cópias da biblioteca.
  • Faça uma cópia pelo menos uma vez por mês e antes de mudar de computador, limpar dados do navegador ou importar uma lista grande.

Restaurar, importar ou recomeçar

  • Escolha Selecionar ficheiro em Dados e definições para restaurar uma cópia JSON ou importar uma lista CSV. Restaurar JSON substitui o catálogo atual.
  • Apagar base de dados local elimina permanentemente o catálogo deste navegador. Faça primeiro uma cópia.

Se algo não funcionar

  • Se não encontrar um livro, pesquise uma palavra do título ou o apelido do autor.
  • Se a câmara não ler o código, use mais luz, mantenha-o parado ou escreva o ISBN à mão.
  • Os dados são locais. Para os usar noutro computador, faça uma cópia aqui e restaure-a lá.
