Easy guide to Papa Libro

A calm, practical guide for keeping track of books without needing technical knowledge.

The three important questions

  • Do we have this book?
  • Where is it kept?
  • Who has borrowed it?

Before you begin

  • Papa Libro works in the browser and does not require an account or password. The catalogue stays on this computer and in this browser.
  • Use the menu on the left: Home, Catalogue, Collections, Loans, Inventory and Data & settings. On a phone, press the three-line menu button.

Find a book

  • Use the search box at the top. Type part of the title, the author, an ISBN or a tag.
  • Each result says Available when a copy is in the library, On loan when all copies are out, or No copies when only the record exists.
  • Select a cover to see the complete record and its location.

Add a new book

  • Press Add book. The title is the only essential field.
  • Choose a collection and write a clear location, for example: Main room - Shelf B - Level 2.
  • Enter how many physical copies you own, then choose Save book. You can correct the details later.

Add a book with its barcode

  • Press Add book and type the ISBN printed below the barcode, then choose Fill from ISBN. Review the result before saving.
  • You can also choose Scan ISBN or Camera and allow camera access. Keep the barcode still and well lit. If it does not scan, type the numbers or use a USB barcode reader.

Create collections

  • Collections make the catalogue easier to use. Examples: Children, Cooking, Local history or Reading club.
  • Open Collections, choose New collection, give it a name and select Create collection. Choose it when adding or editing a book.

Lend and return

  • Open an available book and choose Lend a copy. Enter the person’s name, the loan date and the expected return date, then confirm.
  • When it comes back, open Loans and choose Return. The copy becomes available immediately.

Check individual copies

  • Open Inventory to see every physical copy, its internal code, location, loan status and condition. This is useful during a stock check.

Make a backup

  • Open Data & settings and choose Download JSON backup. Save the downloaded file somewhere easy to find, such as Documents > Library backups.
  • Make a backup at least once a month and before changing computers, clearing browser data or importing a large list.

Restore, import or start again

  • Choose Select file in Data & settings to restore a JSON backup or import a CSV list. Restoring a JSON backup replaces the current catalogue.
  • Delete local database permanently removes this browser’s catalogue. Download a backup first.

If something does not work

  • If a book is not found, search using one word from its title or the author surname.
  • If the camera cannot read a barcode, add light, hold it still or type the ISBN by hand.
  • Your data is local. To use it on another computer, make a backup here and restore it there.
