# Papa Libro

Papa Libro es una aplicación web libre de [VhEscribano](https://vhescribano.com/) para catalogar libros, organizar colecciones y controlar préstamos en bibliotecas personales, escolares o comunitarias.

Está pensada para funcionar de forma sencilla, sin cuentas ni suscripciones: los datos se guardan en el navegador y se pueden exportar como copia de seguridad.

## Funciones principales

- Catálogo de libros con ficha, ISBN, ubicación, etiquetas y notas.
- Colecciones para organizar el fondo por tema, sala o público.
- Control de copias físicas y disponibilidad.
- Registro de préstamos, devoluciones y fechas previstas.
- Búsqueda por título, autor, ISBN y etiquetas.
- Alta manual, consulta por ISBN y lectura de códigos de barras cuando el navegador lo permite.
- Importación y exportación de datos en JSON y CSV.
- Guía de uso integrada y documentación imprimible.

## Abrir la aplicación

No necesita instalación. Abra [index.html](index.html) con un navegador moderno.

Para un uso habitual, se recomienda Microsoft Edge, Google Chrome o Firefox. El lector de códigos de barras con cámara depende del navegador y de los permisos concedidos.

## Copias de seguridad

La información se guarda localmente en el navegador. Use **Datos y ajustes → Descargar respaldo JSON** con regularidad, especialmente antes de cambiar de ordenador o borrar datos del navegador.
